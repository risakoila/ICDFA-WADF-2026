--------------------------------------------------------------
TOPICS COVERED (NETWORK LAYER)
--------------------------------------------------------------
- Network layer overview: the PDU is the packet; the layer
  handles logical addressing, routing and forwarding.
- Common protocols: IPv4, IPv6, ICMP, IGMP.
- OSI model mapping to the TCP/IP model.
- Data encapsulation at the sender.
- Packet forwarding using source/destination addresses and
  routing tables.
